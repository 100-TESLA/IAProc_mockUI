## Brand & Style

This design system is engineered for mission-critical enterprise procurement orchestration. Designed for chief procurement officers, global sourcing directors, and enterprise finance controllers, the interface delivers institutional-grade confidence, absolute data precision, and frictionless workflow throughput.

The visual style blends **Corporate Modernism** with **Engineered High-Density Utility**:
- **Clarity over decorative flourish**: Visual structures are disciplined, prioritizing content visibility, transaction transparency, and lightning-fast scanning across enterprise supply networks.
- **Cognitive comfort under heavy load**: Dense analytical grids and procurement reconciliation workflows are tempered by deliberate neo-grotesque type scales, crisp visual thresholds, and calming deep sapphire accents.
- **Augmented Copilot presence**: AI assistance is integrated as an organic operational partner—anchored into persistent context panels with quiet, frosted structural depth rather than distracting neon accents.

## Colors

The palette establishes an authoritative, precise enterprise operational environment:

- **Primary Sapphire (`#2563EB`)**: Drives focused primary workflows, focal interactions, active table selections, and core commitment actions (e.g., purchase order approvals, contract execution).
- **Deep Slate Anchoring (`#0F172A`)**: Deployed for persistent navigation sidebars, high-level grouping containers, and deep-contrast system controls.
- **System Neutral Canvas (`#F8FAFC` base, `#FFFFFF` cards, `#E2E8F0` borders)**: Forms a clean, distraction-free substrate that reduces eye strain during multi-hour spend analysis sessions.
- **Workflow State Tokens**:
  - *Complete / Verified / In-Policy*: Deep Emerald (`#059669` fill, `#ECFDF5` container, `#A7F3D0` outline)
  - *Pending / Exception / Needs Review*: Deep Amber (`#D97706` fill, `#FFFBEB` container, `#FDE68A` outline)
  - *Processing / Negotiating / In-Transit*: Deep Sapphire (`#2563EB` fill, `#EFF6FF` container, `#BFDBFE` outline)
  - *Breach / Over-Budget / Rejected*: Crimson Rose (`#DC2626` fill, `#FEF2F2` container, `#FECACA` outline)
- **AI Copilot Accent**: Subtle gradient ramp transitioning from Deep Sapphire (`#2563EB`) to Precision Teal (`#0D9488`) with 8% alpha washes on docked structural surfaces.

## Typography

The typographic hierarchy combines structural balance with high-density legibility:

- **Display & Headlines (`Manrope`)**: Provides balanced, authoritative geometry for module banners, KPI metrics, and high-order modal titles. It establishes clear visual landmarks without feeling decorative or informal.
- **Body & Numerical Data (`Hanken Grotesk`)**: Provides razor-sharp micro-legibility at 12px–14px sizes. Open apertures and distinct glyph forms prevent confusion between similar characters (such as `0` and `O`, or `1` and `l`) in line-item tables, SKU tables, and tax reconciliation records.
- **Tabular Alignment**: All currency amounts, metric units, and order indices strictly enforce `font-variant-numeric: tabular-nums` to maintain vertical decimal alignment across multi-thousand-row data grids.

## Layout & Spacing

This design system uses an asymmetrical, high-utility operational layout designed for 1080p and 1440p enterprise displays, while scaling gracefully down to laptop and tablet devices.

- **Desktop Master Canvas (1440px+)**:
  - Fixed Collapsible Navigation Rail: `260px` expanded, `64px` collapsed.
  - Fluid Operational Data Center: 12-column variable grid with `16px` gutters.
  - Docked AI Copilot Inspector Panel: Fixed `380px` drawer anchored on the right viewport edge.
- **Tablet Layout (768px - 1024px)**:
  - Sidebar collapses to icon-only mode (`64px`).
  - AI Copilot switches from docked persistent mode to an overlaid sheet (`400px` slide-over).
  - Data grids activate horizontal scroll pins on freeze-columns (e.g., PO ID and Action menus).
- **Mobile Exceptions (< 768px)**:
  - Top navigation bar replaces side navigation; outer margin contracts to `16px`. Data grids collapse into stacked card-based ledger items.

## Elevation & Depth

To preserve legibility within information-dense screens, this design system minimizes heavy dropped shadows in favor of **structural borders paired with tinted ambient depth**:

1. **Base Surface (Level 0)**: `#F8FAFC` background. Completely flat.
2. **Structural Workspace Layer (Level 1)**: White (`#FFFFFF`) containers framed by crisp 1px solid borders (`#E2E8F0`). Flat surface; borders delineate functional groupings.
3. **Interactive & Hover Elements (Level 2)**: Subtle elevation for hovered rows, tooltips, or active dropdown triggers: `0px 2px 4px -1px rgba(15, 23, 42, 0.06), 0px 4px 6px -1px rgba(15, 23, 42, 0.04)`.
4. **Docked AI Copilot Panel (Level 3)**: Semi-translucent layered backdrop (`rgba(255, 255, 255, 0.94)` with `backdrop-filter: blur(12px)`), separated by a distinct left border (`#CBD5E1`) and a directional ambient cast: `-4px 0px 24px -2px rgba(15, 23, 42, 0.06)`.
5. **Overlays & Dialogs (Level 4)**: Modal dialogs, approval flowsheets, and critical alerts: `0px 20px 25px -5px rgba(15, 23, 42, 0.1), 0px 8px 10px -6px rgba(15, 23, 42, 0.05)`.

## Shapes

The shape system leverages **Rounded Geometry (Level 2)** to provide an inviting, modern workspace without sacrificing pixel economy:

- **Base Radius (`0.5rem` / `8px`)**: Applied to form inputs, buttons, standard card panels, action dropdown menus, and data filter buttons.
- **Large Radius (`1rem` / `16px`)**: Applied to high-level metric hero cards, floating context panels, and modal containers.
- **Extra-Large Radius (`1.5rem` / `24px`)**: Applied to specialized prompt entry fields within the AI Copilot conversational input dock.
- **Micro Radius (`0.25rem` / `4px`)**: Reserved for internal data grid checkboxes, sub-elements within dense rows, and inline code/SKU tokens.

## Components

### Buttons
- **Primary**: Solid sapphire background (`#2563EB`), crisp contrast white typography (`#FFFFFF`), `0.5rem` border radius, `0.5rem 1rem` padding. Focused states display a 2px offset ring in `#93C5FD`.
- **Secondary**: Transparent background, 1px solid border (`#E2E8F0`), deep slate text (`#0F172A`). Hover transitions to `#F1F5F9`.
- **Tertiary / Ghost**: Zero border, slate text (`#475569`). Hover adds `#F8FAFC` fill.
- **Copilot Action**: Deep Sapphire to Precision Teal edge-gradient outline, `#FFFFFF` interior, subtle sapphire hover wash.

### Form Inputs & Selectors
- Standard height of `36px` for dense enterprise layouts.
- Neutral state: White surface (`#FFFFFF`), border `#E2E8F0`, slate placeholder (`#94A3B8`).
- Focus state: Border transitions to `#2563EB` with an ambient `0 0 0 3px rgba(37, 99, 235, 0.15)` focus ring.
- Error state: Border transitions to `#DC2626` with `0 0 0 3px rgba(220, 38, 38, 0.12)`.

### High-Density Data Grid
- **Headers**: Surface `#F8FAFC`, bottom border 1px solid `#CBD5E1`, text uppercase `label-sm` in `#475569`, column sorting indicators in `#94A3B8`.
- **Rows**: Explicit `40px` dense height or `48px` standard height. Alternating rows remain white; hover applies `#F8FAFC`.
- **Active / Selected Row**: Tinted sapphire background (`#EFF6FF`) with a persistent `2px` left border marker (`#2563EB`).
- **Cells**: Inline padding `0.75rem`, vertically centered, border-bottom 1px solid `#F1F5F9`.

### Status Badges
- Pill-shaped (`9999px` radius) or soft micro-radius (`4px`). Padding: `2px 8px`. Font: `label-sm`.
- **Approved / Active**: Fill `#ECFDF5`, text `#065F46`, border 1px solid `#A7F3D0`.
- **Pending / In Review**: Fill `#FFFBEB`, text `#92400E`, border 1px solid `#FDE68A`.
- **In Negotiation**: Fill `#EFF6FF`, text `#1E40AF`, border 1px solid `#BFDBFE`.
- **Rejected / Critical**: Fill `#FEF2F2`, text `#991B1B`, border 1px solid `#FECACA`.

### Docked AI Copilot Panel
- Positioned persistently on the right side of the canvas with a collapsible toggle.
- Features a subtle gradient header badge (Sapphire to Teal) paired with a high-translucency frosted glass background.
- Conversational chat cards use `#FFFFFF` backgrounds with crisp `#E2E8F0` borders for user prompts, and soft sapphire-tinted backgrounds (`#F8FAFC`) with `#2563EB` accent edges for AI procurement recommendations.
- Interactive recommendation blocks include direct action triggers (e.g., "Auto-reconcile PO #8921", "Trigger Vendor RFP") directly inside the stream.

### Cards & Metrics
- Background `#FFFFFF`, border 1px solid `#E2E8F0`, roundedness `0.5rem`.
- KPI summary blocks incorporate prominent tabular metric values (`headline-lg`), a descriptive label (`label-md`), and inline micro-sparklines or change delta pills.
