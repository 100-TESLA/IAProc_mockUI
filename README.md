# IAProc_mockUI

Mock UI cho hệ thống IAProc, gồm các giao diện phục vụ quy trình quản lý và phê duyệt nhà cung cấp.

## Module 1: Quản lý Nhà cung cấp (QLNCC)

Module QLNCC có các giao diện được tổ chức theo actor và các subnavigation tab trong menu **Hồ sơ nhà cung cấp**.

### Actor: Bộ phận mua sắm

Ba tab dành cho bộ phận mua sắm:

1. [Hồ sơ nhà cung cấp](./QLNCC/code-ui-1.html)
2. [Bản nháp & Hồ sơ cần xử lý](./QLNCC/code-ui-2.html)
3. [Danh mục Loại NCC](./QLNCC/code-ui-3.html)

### Actor: Cấp phê duyệt

Ba tab dành cho cấp phê duyệt:

4. [Hồ sơ chờ phê duyệt](./QLNCC/code-ui-4.html)
5. Lịch sử đã xét duyệt
6. Tra cứu Danh mục NCC

Hiện tại, repository có giao diện cho tab **Hồ sơ chờ phê duyệt**; giao diện cho hai tab còn lại chưa có file HTML tương ứng.
